# Manducat

Прототип пошаговой карточной игры для двух игроков на чистом JS. Всё в одном файле — `index.html`, открывается в браузере без сборки.

Режимы: против ИИ (3 уровня сложности) и вдвоём за одним экраном.

Параметры (очки для победы, очки за G и M, состав армии, веса ИИ) — в начале `<script>` в `index.html`.
