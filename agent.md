# Agent

Главные инструкцияи Агенту

## Файлы

- 'architecture.md' - актуальная архитектура проекта и правила зависимостей между модулями.
- `rules.md` — правила игры в мандукат, короткий файл, где описываются все ньансы битвы 1 на 1.
- `current_state.md` — краткое текущее состояние проекта.
- `agent.md` — эта инструкция.

## Правила


- `agent.md` трогать нельзя. Этот файл меняет только пользователь.
- Перед правкой механик сначала сверяйся с текущими md-файлами, потом меняй код, потом синхронизируй документы.
- Прежде чем вносить изменения в игру сверяйся с architechture.md
- Если меняется архитектура или ответственность модулей — обновляй `architecture.md`
- current_state.md - используется, чтобы писать какие вещи сейчас в работе, например, если делаются изменения, которые нужно последовательно делать - то этот md используется для того, чтобы хранить прогресс. Старые завершенные изменения - удаляем оттуда
- Везде, кроме этого файла используется Английский язык, даже если я что-то пишу по русски - то ты переводишь.
